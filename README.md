# Embedded C Projects

A collection of embedded systems projects developed using Embedded C and microcontrollers, with a focus on peripheral interfacing and hardware control.

## Projects

### 1. Environment Monitor
An embedded project focused on environmental parameter monitoring using sensors and microcontroller interfacing.

### 2. Smart Industry Monitoring System
An embedded project exploring industrial monitoring and sensor-based data acquisition.

## Technologies and Concepts

- Embedded C programming
- LPC2129 microcontroller
- UART serial communication
- I2C communication
- Timers and interrupts
- ADC interfacing
- Sensor interfacing
- Makefiles and modular programming
